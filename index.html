Аудитория

Для кого этот курс

Без предположения навыков программирования. Git и GitHub — как инструмент памяти и контроля, не как DevOps.

Предприниматель

Ведёте свой проект и устали от хаоса в чатах. Получаете память проекта, порядок и отчёты из актуального контекста.

Консультант

Ведете проекты для клиентов. Получаете передаваемый контекст, аудит изменений и понятную структуру под заказчика.

Результат

Что меняется после курса

  • Контроль документации Документы собираются из актуального контекста, а не переписываются с нуля.
  • Единый контекст для AI Не нужно каждый раз объяснять Cursor, кто участники и какие решения уже приняты.
  • История поля Git фиксирует кто, когда и что изменил в знаниях проекта — не только в коде.

Формат

Три онлайн-занятия

Около двух часов каждое. Между днями — самостоятельная работа над своим проектом и общий Telegram-чат группы.

  1. День 1

    Cursor и GitHub

    Инструменты и инфраструктура: чат vs агент, репозиторий как память, commit / push / pull, ритуал синхронизации.

  2. День 2

    Информационное поле

    Заводите свой проект: люди, решения, процессы, артефакты. Структура под ваш рабочий процесс — без готового шаблона.

  3. День 3

    Разбор проектов

    Мастермайнд: показ проектов, ответы на вопросы пяти дней практики, корректировка конфигурации.

День 1 → 2 дня практики → день 2 → 5 дней ведения проекта → день 3
